# AXE Despacho Mobile

Aplicativo de campo Android e iOS do **AXE Despacho**. Este repositório é exclusivo do cliente mobile (React + Capacitor) e não contém banco de dados, serviços de PABX ou backend da central.

**Backend oficial:** [jeffaxe81/dispatch](https://github.com/jeffaxe81/dispatch).

O frontend mobile acessará a central somente por APIs HTTPS autenticadas. Rastreamento GPS nativo em segundo plano, armazenamento local criptografado e instalação corporativa exigem implementação, permissão e homologação específicas por plataforma.

> Estado inicial: repositório criado e estrutura mobile em desenvolvimento.
